# WARDENFALL Quick Start

1. Extract the ZIP to a writable local folder.
2. Run `uegame.exe`.
3. Press Enter or Space.
4. Choose the visible room contract with 1 or 2.
5. Follow the objective text, clear the required rooms, choose rewards, and use the lit exit.
6. On floor 3, break the Warden's guard and attack during the stagger window.

## Controls

- WASD: move
- Mouse: look
- F: attack
- 1/2/3: choose contract or reward
- Escape: pause/resume; cancel confirmation
- R: restart
- Q: quit to desktop
- Enter/Space: begin or accept confirmation

The demo requires no editor, MCP bridge, console command, installer, account, or network connection.
